# US Shop POS - Small Business POS System 🇬🇭
A complete Point of Sale built with Python Flask for shops in Accra.

**Live Demo Code:** github.com/Zacharia-code/us-shop-pos
**Built on:** Acer Laptop + VS Code

### 🚀 Features
- Fast Sales + Receipt Printing
- Stock Management with Low Stock Alerts
- Customer Credit Book (who owes)
- Daily Sales Reports & Dashboard
- Barcode Ready

### 🛠️ Tech Stack
Python | Flask | SQLite | HTML | CSS | Git

### ▶️ How To Run
pip install -r requirements.txt
python app.py
